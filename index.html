MollyPrefixes

Цветные и анимированные префиксы для групп LuckPerms. Каждый префикс собирается из двух PNG: фона и надписи.

Установка

  1. Подготовьте Paper или Purpur. Сборка проверена на Purpur 1.21.8 с Java 21. API плагина рассчитан на Paper 1.21.4 и выше.
  2. Остановите сервер. Положите MollyPrefixes-1.0.0.jar в plugins/. Если LuckPerms ещё отсутствует, добавьте LuckPerms-Bukkit-5.5.91.jar из комплекта. Если LuckPerms уже установлен, используйте имеющийся JAR.
  3. Запустите сервер. Плагин создаст plugins/MollyPrefixes/config.yml и соберёт MollyPrefixes-pack.zip. В игре с правом администратора выполните /mollyprefixes status.
  4. Настройте доставку ZIP игрокам и откройте /prefixes. На чистой установке доступно нейтральное оформление для группы default.

При обновлении сохраните папку plugins/MollyPrefixes/. Она содержит настройки, назначения Unicode и выбор игроков. Старые раздельные конфиги при первом запуске переносятся в новую структуру, исходники сохраняются как .bak.

Доставка ресурспака

Без сборщика

  1. Укажите resource-pack.integration: standalone.
  2. Разместите сгенерированный plugins/MollyPrefixes/MollyPrefixes-pack.zip на хостинге файлов. Прямая HTTP(S)-ссылка должна отдавать ZIP и быть доступна игрокам.
  3. Запишите ссылку в resource-pack.delivery-url, оставьте resource-pack в server.properties пустым и выполните /mollyprefixes reload. При изменении локального ZIP обновите файл по указанной ссылке. Плагин вычисляет SHA‑1 по локальному архиву.

С установленным сборщиком

Выберите один режим resource-pack.integration. Режим auto выбирает единственный обнаруженный сборщик и переходит в standalone, если сборщиков несколько или их нет. Доставку игрокам настраивайте в выбранном сборщике.

Если у сервера уже есть отдельный пак, добавьте его локальный ZIP или распакованную папку в resource-pack.collision-sources. Пути считаются от корня сервера. Для ручного объединения перенесите ресурсы MollyPrefixes и добавьте его провайдер reference в массив providers вашего assets/minecraft/font/default.json.

Встроенные анимации требуют совместимого текстового шейдера. Причину конфликта видно в /mollyprefixes status. Для ItemsAdder проверьте text_effects.enabled в его конфиге. Режим animations.mode: external использует маркеры внешнего пака, bundled добавляет встроенный шейдер, off отключает анимации.

Оформление групп LuckPerms

  1. Подготовьте два прозрачных PNG одинакового размера, до 256 × 256. Фон лучше сделать в градациях серого, чтобы он хорошо тонировался. Текстовый слой задаёт белую надпись.
  2. Поместите PNG в папку plugins/MollyPrefixes/textures/. В config.yml → prefixes добавьте запись с уникальным ID. Укажите group с точным именем группы LuckPerms, name для подписи и пути background и text от папки MollyPrefixes.
  3. Примените конфиг через /mollyprefixes reload. Проверьте назначение через /mollyprefixes glyphs <id>.

Игрок получает меню старшей настроенной привилегии. Сначала учитывается вес группы LuckPerms, затем приоритет её префикса в текущем контексте и основная группа. Unicode и смещение назначаются автоматически. Если нужно задать Unicode вручную, используйте background.unicode, text.unicode и shift.unicode в диапазоне U+E000–U+F8FF.

Раздел rank-color.colors задаёт обычные цвета. Раздел animations.effects задаёт доступные пресеты. Поля ranks и permission ограничивают доступ. В rank-backgrounds.defaults можно задать подпись, смещение и эффект по умолчанию для группы.

Меню игрока и администратора

Игрок открывает /prefixes или /cosmetics и выбирает цвет либо анимацию. Анимации идут подряд по типам. Для одноцветного эффекта можно выбрать оттенок из палитры ранга. «Свой цвет (HEX)» позволяет ввести RGB, посмотреть предпросмотр и вернуться к недавним цветам. «Сбросить» возвращает префикс LuckPerms.

Администратор открывает /mollyprefixes → Привилегии и выбирает группу. ЛКМ переключает доступ к конкретному цвету или эффекту, ПКМ возвращает ограничение из YAML. Кнопка «Свой HEX» управляет собственным цветом отдельно. Изменения записываются в admin-state.yml.

Чат, TAB и плейсхолдеры

MollyPrefixes добавляет персональный префикс в LuckPerms. В настройках чата и TAB укажите плейсхолдер префикса LuckPerms, который поддерживает ваш форматтер. Установите приоритет rank-display.weight выше приоритета обычного префикса, если личное оформление должно его перекрывать.

Если установлен PlaceholderAPI, доступны %mollyprefixes_prefix%, %mollyprefixes_rank%, %mollyprefixes_rank_tab%, %mollyprefixes_rankname%, %mollyprefixes_rankcolor% и %mollyprefixes_rankbg%. Для формата MiniMessage используйте %mollyprefixes_rank_minimessage% там, где форматтер разбирает MiniMessage после подстановки.

Форматтер должен сохранять Unicode и полный RGB. Замена оттенков на 16 цветов ломает служебные маркеры анимаций.

Команды и права

КомандаДействие
/prefixesОткрыть меню игрока.
/prefixes color <#RRGGBB>Применить свой цвет.
/mollyprefixes [admin]Открыть админ-панель. Короткий вариант — /mprefix.
/mollyprefixes ranksОткрыть настройки привилегий.
/mollyprefixes statusПроверить сборщик, ZIP и статус анимаций.
/mollyprefixes reloadПрочитать конфиг заново и пересобрать ZIP.
/mollyprefixes glyphs <id>Показать Unicode фона, сместителя и текста.
/mollyprefixes code <id> <цвет>Скопировать команду LuckPerms для постоянного группового префикса.

mollyprefixes.use открывает меню игрока, mollyprefixes.custom-color даёт доступ к HEX. Оба права включены по умолчанию. mollyprefixes.admin по умолчанию доступно операторам.

Если префикс не отображается

  • Пустое меню. Проверьте имя группы в prefixes.<id>.group, наследование в LuckPerms и право mollyprefixes.use.
  • Вместо картинок символы или квадраты. Проверьте, что клиент принял свежий пак и в minecraft:default есть ссылка на шрифт MollyPrefixes.
  • Глифы работают, анимации стоят. Посмотрите статус шейдера и проверьте, сохраняется ли полный RGB в вашем формате чата.
  • В чате старый префикс. Проверьте, какой плейсхолдер использует форматтер и какой приоритет префикса выдаёт LuckPerms.
